# Changelog

All notable changes to Trazo are documented in this file.

## [0.1.0 (Pre-release)] - 08/09/2026

- The REAL First Day of the Trazo Compiler.
- Now Trazo compiles to C.
- Radar has already been implemented with a small-scale version.
- Trazo added symbiosis with C by including the ability to include C files.
- Watch out! Trazo is unsafe, and almost any code you want to compile will be compiled without being checked.

## [0.1.0-alpha (Pre-release)] - 07/06/2026
- The first day of The Trazo Compiler.
